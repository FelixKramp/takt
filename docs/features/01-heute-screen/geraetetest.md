# Gerätetest Takt

Dauer: etwa 15 Minuten plus eine Stunde Warten für den Hintergrundtest. Das Band kann immer nur mit einer App verbunden sein.

## Umzug
1. In OpenStrap Edge unter Einstellungen die Datenbank exportieren und die Datei auf dem Handy speichern.
2. OpenStrap Edge schließen, Band dort trennen. Die App noch nicht löschen.
3. Takt-APK installieren, dabei die Installation aus dieser Quelle erlauben.
4. Takt öffnen, Datenbank importieren, Band koppeln.

## Prüfen
